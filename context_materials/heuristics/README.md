# Heuristic source inventory

`source/` is a verbatim snapshot of the complete YAML heuristic directory used
during this research handoff. Index files define curated loading sets; not
every rule in the directory is active or promoted. Start with
`_index-td-stage1.yaml` for TD and `_index-cv.yaml` for CV. Historical,
near-miss, duplicated, and unpromoted rules are retained for auditability, not
as instructions to concatenate every file into one prompt.

See `docs/03-heuristics.md` for the operational synthesis.
