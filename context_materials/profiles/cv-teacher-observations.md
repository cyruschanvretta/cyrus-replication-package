# Conventions teacher distinctions

Read once for meaning, then inspect where repair was required. Distinguish an isolated
surface distraction, recurring but immediately repairable patterns, repeated
reconstruction of sentence relations, and loss of a proposition. Record which domains
carry the effect rather than treating all flags alike.

Check the whole response. One clean sentence does not establish consistent control,
and one local error does not erase it. Require observable evidence for both the current
description and the nearest stronger description.
