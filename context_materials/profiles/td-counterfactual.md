# Topic-development counterfactual checks

Test two alternatives without naming a score. For the stronger description, identify
the missing witness in support, linkage, explanation, or progression. If none is
missing, the weaker description is not defensible. For the weaker description,
identify what the response demonstrably does beyond merely naming or listing.

Apply the tests to the whole response. Uneven evidence should remain uneven in the
profile rather than being rounded into a single impression.
