# Topic-development first principles

Observe how the response builds meaning. Keep task engagement, position stability,
support, explanation, and organization separate. Length, vocabulary, paragraph count,
and correctness of conventions are not substitutes for developed ideas.

A reason is not developed merely because it is repeated or followed by an example.
Ask what the detail establishes, how it connects to the writer's position, and whether
the sequence advances the reasoning. Plain language can carry strong development;
polished language can carry very little.

Judge only the current response and its ephemeral task material. Do not infer a result
from topic, item identity, membership, or resemblance to another response.
