# Adjacent-band counterfactual check

Before finalizing, write two short internal tests:

- Higher-band test: name the exact required condition that is absent if the response
  does not earn the next band. If no required condition is absent, move up.
- Lower-band test: name the exact strength that exceeds the lower band. If no such
  strength is observable, move down.

Apply both tests to the whole response. Do not let one polished sentence lift an
otherwise weak response, and do not let one local error lower an otherwise controlled
response. When evidence is uneven, follow the rubric's required conditions instead of
splitting the difference.
