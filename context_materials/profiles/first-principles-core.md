# First-principles scoring procedure

Work only from the invariant rubric, the current response, deterministic observations,
and any authored task material explicitly supplied for this response. Never infer a
score from a remembered topic, item identity, response-set membership, demographic
signal, or similarity to an example.

1. State the observable evidence relevant to every load-bearing rubric condition.
2. Identify the lowest band whose complete conditions are met; do not average unrelated
   strengths and weaknesses into a vague impression.
3. Test the proposed band against the band immediately below and immediately above.
4. Prefer the lower band when a required condition for the higher band is absent. Do
   not prefer the lower band merely because the response is imperfect.
5. Return the requested compact categorical profile. Software maps that profile to the
   task's score scale using the rubric; do not invent a separate arithmetic shortcut.

Deterministic observations are measurement aids. Confirm them against the response and
use their distribution and effect on meaning; never map a raw count directly to a band.
Hard gates reported as already passed or failed by software are authoritative. Never
invert a numeric comparison or re-apply a gate that software has already resolved.
