# Structural analytic profile

Build a compact profile before selecting a score.

For Topic Development, profile: task relation; opinion clarity; opinion consistency;
distinct supporting reasons; support sufficiency; proportion of reasons actually
unpacked; specificity consistency; link from evidence to opinion; organization; and
progression. Treat each as observable, not inferred from length or fluency.

For Conventions, profile: scoreable word count; sentence-boundary control; syntax and
clause joining; grammar and agreement; usage; spelling patterns; punctuation and
capitalization; recurrence across the response; and effect on reading rhythm and
meaning. Verify deterministic flags because names, dialect, and deliberate style can
create false positives.

For Open Response, profile: direct answer; correctness relative to task material;
relevant support; explanation; and any item-specific condition in the authored rubric.

Map the completed profile to the rubric only after the profile is stable. Never use a
weighted average unless the authored rubric explicitly calls for one.
